# Handoff SM-T585 mainline

## Charter
- Scope: mainline Linux 7.3 bring-up of the SM-T585 (gtaxllte), our kernel fork in `src/mainline` (branch `gtaxllte`), build tooling in `kernel/`.
- Mode: interactive bring-up with the user. The user flashes BOOT (`!` command); I stage the image in `/tmp` on the device and give the sha1.
- Terms: "stage 1" = our busybox initramfs boot image; "#N" = kernel build number (`uname -v`).

## Conclusions
- Build: see CLAUDE.md. Config = defconfig + `kernel/gtaxllte-stage1.config` + `kernel/gtaxllte-builtin.config`. dtbs_check needs `export PATH=kernel/.venv/bin:$PATH`.
- Device access: `python3 /home/istvan/workspace/galaxy-tab-a-2016/kernel/tools/devsh.py "<cmd>" <timeout>` (use the absolute path). The first command after a USB re-plug may come back garbled; repeat it. Host serves `kernel/out` via `python3 -m http.server -b 172.16.42.2 -d kernel/out 8000`, device fetches with `wget` into `/tmp`.
- Flash: `dd if=/tmp/boot-stage1.img of=/dev/mmcblk0p9 bs=1M conv=fsync && head -c <size> /dev/mmcblk0p9 | sha1sum`; reboot via the power button (a `reboot` at the end of the devsh command does not get through).
- Modules can be swapped without flashing (LOCALVERSION_AUTO off): build, copy the .ko to `kernel/out/...`, `rmmod`/`insmod`. DT changes need a flash.
- Battery: `/sys/class/power_supply/sm5703-charger` (online, status, health, temp, usb_type, limits, `charge_control_{start,end}_threshold`; end=100 = limiter off; lower start before lowering end). Battery NTC zone: `/sys/class/thermal/thermal_zone1` (battery-thermal). Logger: `kernel/out/batt/ntclog.sh` (needs `/tmp/i2cx`).
- Kernel commits on gtaxllte: a1cf85447 (bindings), 3ece1d800 (ADC supply, NTC table in mV), aa17ce4a9 (charger). BOOT holds #31 = these except the charger stop action (flashed: `stopping` flag; committed: disable_delayed_work_sync, module-swap verified).
- PMIC (S2MPU05 @ i2c-0 0x66, read with /tmp/i2cx): PWRONSRC 0x09, CTRL1 0x0d, CTRL3 0x15. SM5703 MRSTB (gpc7-4) is not driven by mainline.

## Open points
- dtbs_check on exynos7870-gtaxllte.dtb is clean (ADC vdd-supply = vdd_ldo3 by analogy; local audio bindings). Flashed in #31. The real supply makes the ADC report a mV scale: the NTC table is now in mV.
- Power key: `kernel/tools/pwrkeyd` (short = screen black via VT2 + touch grab, 2 s hold = power off), in the initramfs since #31. Backlight stays on until a DSI panel driver exists.
- Charger review findings fixed (teardown race via a disable_delayed_work_sync devm action; TEMP -ENODATA without a valid NTC read).
- Charger zones verified on HW with the debug param `sm5703_charger.temp_offset` (script `kernel/out/batt/zones.sh`). DCP run (`kernel/out/batt/dcpzones.sh`): the cool cap (850 mA) limits for real, the warm cap (1300 mA) is programmed but above the ~1 A actual current.
- Still open, optional: linear_range/regmap_field, monitored-battery, write the GPIO only on change.
- ADC channel 3 (battery voltage): the downstream table says 3.80 V where the FG shows 3.64 V; unexplained, unused.
